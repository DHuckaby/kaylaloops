# Agent Instructions

## Core Preference: Configuration over Customization
When working in this codebase, always prefer configuring existing systems (e.g., Hugo/Blowfish `.toml` files, theme parameters, built-in shortcodes) instead of implementing custom workarounds (e.g., manual CSS overrides, custom scripts, or "hacky" fixes). 

- **Always** check official documentation for a configuration-based solution first.
- **Avoid** adding custom CSS files unless a design requirement cannot be met by the theme's color schemes or standard parameters.
- **Maintain** the idiomatic structure of the chosen tools.
